Fanzine para imprimir y compartir [Fanzine-Lais-Nerdearla_Imprimir.pdf](https://github.com/user-attachments/files/33741014/Fanzine-Lais-Nerdearla_Imprimir.pdf)

Como Armar el Fanzine:

1) Imprimir las hojas en papel común doble faz sin ajustar. 

2) cortar x las lineas de puntos
   
3) Acomodarlos en orden: la hoja 1 es la base y encima pones la 2, la 3, la 4 etc (tienen el numero al costado en el pdf!)
   
4) Acomodás, puteas a la derecha y doblas todo a la mitad.
   
5) Listo!
